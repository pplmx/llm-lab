# 交互为什么这样设计

README 的操作表只写每个控件做什么。这里记的是**为什么是现在这样**——每一条都对应一个曾经
不成立的东西，改回旧做法会重新出问题。

返回 [README](../README.md)。

## 撤销为什么在顶栏

原先只有第 7 步卡片上有一个撤销按钮，而那张卡在 1180×720 下还在视口外。顶栏那一行在七个
阶段上都可见，所以按钮挪到了那里，和「重置」并排，只在有东西可撤时出现。

撤销的动作范围是**替换整句提示词**：换成预设、`重置`、采样续写。提示词、选中的 token、
采样记录一起还原。

自己打字**不建立**撤销点——那样 `Ctrl+Z` 会一个字一个字往回退，是编辑器的行为，不是这里的。
但它也**不销毁**已有的撤销点：在预设基础上再打一个字，仍然撤得回原来那句。

## 卡片索引为什么随滚动吸顶

阶段长到了四屏多。打开「残差 / LN」时，读者原先无从得知后面还有三张分析卡片——除了滚，
没有别的导航方式。

索引行**只在一个阶段有两张以上卡片时出现**。目前七个阶段都至少有三张，所以每步都有这一行；
只有退回单卡阶段时它才会消失（`TestReadmeCardIndexRowMatchesTheStages` 看着这条）。

## 固定的格子为什么会在换层时解除

**凡是让这一格不再指同一处**的动作都会解除固定：切换阶段、切换层、切换头、自动播放推进到
下一步、在 token 条里选中另一个 token、以及采样续写。

理由是格子属于它那一行：换行或换层之后留在检查器里，标题与内容会指向不同的东西。

## 采样为什么要自动选中新字节

采样会在提示词末尾追加一个字节。自动选中它，读者就立刻看到刚生成的那个字节的数值——在哪个
阶段都看得到，不用再去 token 条上找。

种子只来自提示词文字，所以温度不变时同一句提示词永远得到同一个结果；拖动温度会改变分布形状，
同一个种子可能落进另一个区间。卡片显示这次抽样用到的种子与区间。

## 逐位置色带为什么默认落在损失最大的位置

这张卡要说明的正是「这个模型经常错」，所以不选时默认描述**损失最大**的那个位置，而不是
t=0——后者对读者没有信息量。

## 方向键为什么分成两套

第 3、4 步的注意力矩阵里，`Shift` + 方向键移动的是格子（↑↓ 换 query，←→ 换 key）；其余
步骤移动的是 token 选择。两个阶段里方向键的含义不同，所以第 3、4 步的步骤条上常驻一行说明
——帮助按钮在置灰状态下点不开，而那正是最需要它的地方。

## `空格` 与 `Enter` 为什么会被方括号焦点吃掉

用 `Tab` 选中某个按钮之后，这两个键先作用于那个按钮（选中「重置」时按 `Enter` 就是按下它），
而不是播放 / 采样。这是对的行为——读者刚用 `Tab` 选中了它——所以 lesson 下方的快捷键行附了
一句说明。

## 滚动键为什么要单独接管

mygo 默认只把滚动键交给「指针下方或焦点链里」的滚动容器。1180×720 下中栏最高的一步有
**两个半屏以上**的内容在视口外（实测随字体浮动，四个平台量到 1742–1885 DIP），所以纯键盘
读者此前根本够不到 lesson 正文和算式块。`PageUp` / `PageDown` / `Home` / `End` 因此显式
转发给中栏。

## 切换阶段时的淡入

160ms，只改不透明度、不动位置——这个工具的用法就是在一个固定位置比较两个阶段的数据，位置
一动就无法比较。系统开启「减少动效」时切换是瞬间完成的，没有过渡帧。

## `Esc` 为什么一次清三个状态

自动播放、固定的热力图格子、固定的逐位置预测。三个一起清，读者不用去找是哪一个还锁着。
